# Validation scope

Portable code was adapted from the executed study scripts by replacing input/output locations and removing historical saved-output comparison dependencies. Numerical model definitions, fixed specifications, country sets, validation origins and seeds were retained. Model-output identifiers preserve the machine-readable study lineage and are mapped to published supplementary table labels.

Verification records for this public release are generated outside the repository during author review. `scripts/check_reference_results.py` compares newly generated aggregates against the included locked reference summaries, with floating-point tolerance. `tests/test_offline_policy.py` checks offline defaults, API domain restrictions, caching and request pacing without network access. `scripts/audit_public_tree.py` rejects credential patterns, signed URLs, absolute private paths, private-data files and unexpected binary artifacts before release.

R package versions and numerical libraries can affect optimization and floating-point results. Model coefficients and summary statistics are expected to match within the documented tolerance; randomized permutation outputs additionally depend on the recorded seed, package version and exact execution order. Input hashes identify the frozen study snapshots. A current online WDI response is not claimed to reproduce that historical snapshot.

## Checks performed for this prepared release

- All R entry points parsed successfully. Five mocked tests passed for offline defaults, official HTTPS domain restrictions, cache reuse, minimum spacing and Retry-After handling. No live API requests were made.
- The full 204-country descriptive core, all 12 temporal model specifications (2,448 country-model fits), unit-root checks, the lag-2 VARX and restricted-order ARIMAX validation/scenarios, and temporal residual/leverage diagnostics were recomputed from the frozen private inputs.
- All eight spatial coordinate/adjustment/outcome fits were recomputed. An independent explicit weighted-regression implementation reproduced all 1,632 local other-disease coefficients to about 10⁻¹⁴ absolute error.
- The new age-reference sensitivity recalculated all 408 country-sex profiles and 7,752 residual rows. The three output CSV hashes were identical to the independently checked revision outputs.
- Sixty-two recomputed numeric CSVs were compared against their frozen counterparts and passed at relative tolerance 10⁻⁷ / absolute tolerance 10⁻⁹. One temporal CSV retained identical named columns and values in a different column order; its comparison aligned columns by name. No scientific values changed.
- The default-search and raw-scale ARIMAX branches were refitted in **144 prespecified smoke fits**: country positions 1, 41, 81, 121, 161 and 204; both diseases and scales; both future-SDI scenarios and all four validation origins. Forecast points/limits matched the frozen outputs within 10⁻⁷ relative error. The complete default/raw ARIMAX grid was not refitted during this portability check. Its aggregate summary and figure commands were rerun using the frozen country matrices, kept outside the public repository, together with newly recomputed VARX/benchmark results. All ten aggregate reference checks passed.
- All figure entry points executed successfully for Figures 1–6 and S1–S3. This checks portability of the plotting commands; the previously approved journal TIFF files were preserved. The longer differenced-VARX residual-path sensitivity and the additional all-model temporal evidence summary were syntax/lineage checked and were not rerun in full for this release check.

These checks establish the reported portability scope. They do not represent a new model search, external validation, or a claim that all temporal assumptions hold. Full reproduction requires authorized access to the matching GBD/SDI and historical PM2.5 input snapshots. Preparation scripts and the original snapshot hashes are supplied; current source downloads may contain revised values.
